# company_data — ข้อมูลบริษัท (ไม่ขึ้น GitHub)

โฟลเดอร์นี้อยู่บนคอมหลักเท่านั้น ไฟล์ทุกไฟล์ในนี้ (ยกเว้น README นี้) ถูกกันไว้ใน `.gitignore`
ได้ไฟล์จาก `HRM_company_data.zip` ที่ส่งแยกต่างหาก แล้ววางไว้ตรงนี้:

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `เอกสาร HRM_Work_Management_20261.xlsx` | แบบฟอร์มต้นฉบับสำหรับส่งออก Excel + รายชื่อพนักงาน 12 คน + วันหยุด |
| `Monthly schedule 2026.04 - 2027.03 Rev00.xlsx` | ตารางประชุม/กิจกรรม สำหรับนำเข้า |
| `ตารางกะ 3 Group.pdf` | ตารางกะต้นฉบับ (เก็บไว้อ้างอิง) |
| `master_seed.json` | รายการงานตั้งต้น 22 งาน จาก Template sheet 10 |
| `roster_codes.json` | ตารางกะ 3 Group ที่ถอดจาก PDF (15 เดือน) |
| `roster_fills.json` | ช่องสีเหลือง/เขียวของตารางกะ |

ถ้าไม่มีไฟล์เหล่านี้ ระบบยังเปิดได้ แต่จะไม่มีรายการงานตั้งต้น รายชื่อพนักงาน ตารางกะ และส่งออก Excel ไม่ได้
