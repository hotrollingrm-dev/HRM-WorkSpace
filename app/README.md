# HRM WorkSpace — คู่มือเปิดใช้งาน (Milestone 1)

หน้าตาใช้ธีมกลาง **HRM Hydraulic** (กระจกฝ้า สีสถานะชุดเดียวกับแอป HRM อื่น) รองรับโหมดสว่าง/มืดตามการตั้งค่าเครื่อง

เว็บแอปวางแผนงานรายเดือนของรีดร้อน (Desktop) + หน้า "งานวันนี้" สำหรับมือถือ (PWA) บันทึกลงฐานข้อมูลจริง (SQLite)
**ทำงานในเครื่องเท่านั้น ไม่ส่งข้อมูลออกภายนอก** — ฟอนต์อยู่ในโฟลเดอร์ ไม่ใช้ CDN

## 1. ติดตั้งและเปิด
ดูขั้นตอนเต็มใน **[INSTALL_TH.md](../INSTALL_TH.md)** (คอม Windows + tablet/มือถือ)

สรุปสั้น (Windows): ติดตั้ง Python 3.11+ → ดับเบิลคลิก `install_windows.bat` → วางไฟล์ข้อมูลบริษัทใน `company_data\` → ดับเบิลคลิกไอคอน **HRM WorkSpace** บนเดสก์ท็อป

| หน้า | URL |
|---|---|
| วางแผน (คอม/tablet) | http://127.0.0.1:8000/ หรือ http://<IP คอมหลัก>:8000/ |
| งานวันนี้ (มือถือ/tablet) | http://<IP คอมหลัก>:8000/m.html |

ข้อมูลเก็บที่ `app/data/` · สำรองอัตโนมัติทุกครั้งที่เปิดผ่าน `start_for_tablets.bat` ไปที่ `app/backups/` (เก็บ 30 ชุดล่าสุด)

## 2. ขั้นตอนใช้งานหลัก
1. **ตั้งค่า → ข้อมูลหลัก**: หมวดหลัก → หมวดย่อย → รายการงาน (ตั้งต้น 22 งานจาก Template sheet `10` แก้/เพิ่ม/ปิดได้; ชื่อญี่ปุ่นว่าง = `[รอแปล]`)
2. **แผนรายเดือน**: เลือกเดือน → แผง "ลงงานด่วน" เลือก หมวด → หมวดย่อย → งาน → ลากเลือกหลายวัน → (กะ/เวลา) → บันทึก · หรือคลิกช่องว่างในตารางเพื่อเพิ่มทีละวัน
3. คลิกหัววันที่ / ช่องที่มีงาน → แผงรายละเอียดวัน (แถบเวลา 08:00→08:00, แก้เวลา/ย้ายวัน/ลบ)
4. **นำเข้า**: อัปโหลด `Monthly schedule…xlsx` เลือกปี → ตรวจตัวอย่าง (ปฏิเสธ/ซ้ำ/ไม่มีเวลา) → ยืนยัน → งานเข้า **ฉบับร่าง**
5. **Publish แผน** → ระบบสร้าง REV ใหม่ + รายการที่เปลี่ยน → มือถือเห็นทันที
6. **ส่งออก Excel** → ไฟล์ตามแบบฟอร์ม HRM ต้นฉบับ (sheet เดือน + `Daily Detail`)
7. มือถือ: ดูงานตามแถบกะ, กด "เริ่มงาน" → "ส่งตรวจ" (Viewer) / "เสร็จแล้ว" (Leader ขึ้นไป)

## 3. บทบาท
**ทุกบทบาท Publish ได้** (ผู้ใช้ยืนยัน) · Admin: ผู้ใช้ทั้งหมด · Foreman: นำเข้า · Leader: แก้ฉบับร่าง, ข้อมูลหลัก, พนักงาน, ยืนยันเสร็จ · Viewer: ดู, ส่งตรวจ

## 3.1 ตารางกะ 3 Group
ตั้งค่า → ตารางกะ 3 Group → **ตรวจและนำเข้าตารางกะจาก PDF** → ดูผลตรวจยอด (WD / ตารางสรุป / วัน Substitution) → **ยืนยันนำเข้า**
- ข้อมูลถอดจาก `ตารางกะ 3 Group.pdf` ม.ค. 2569 – มี.ค. 2570 · ตั้งแต่ ม.ค. 2570 เป็นข้อมูลชั่วคราวตามหมายเหตุใน PDF
- เวลากะทางการ D 08:00–20:15 · N 20:00–08:15
- แตะช่องในตารางเพื่อแก้รายวัน (D → N → H → S) · วันที่แก้มือจะไม่ถูกเขียนทับเมื่อนำเข้าซ้ำ
- ผลที่ได้: แถว "ทีมเข้ากะ" ในแผนรายเดือน, การ์ดกะบนมือถือ (ทีม + รายชื่อ + ตอนนี้กะไหน), ช่อง D/N ของพนักงานใน Excel ที่ส่งออก
- ช่องขอบเหลือง = ทำงานวันหยุดนักขัตฤกษ์ · ช่องขอบเขียว = สลับวันทำงาน (Substitution) · Factory shutdown ปี 2569 = 11 วันตามตาราง
- เป็น **ตารางที่วางไว้** ไม่ใช่การบันทึกการเข้างานจริง

## 3.2 พนักงาน
ตั้งค่า → พนักงาน: 12 คนจาก Template · แตะ A/B/C เพื่อสลับทีม, แก้ตำแหน่ง, ปิดใช้งาน · ชื่อคงเดิม · Excel ส่งออกเติมรายชื่อเรียงตามทีม (ช่อง D/N รายวันยังว่าง จนกว่าจะนำเข้าตารางกะ 3 Group)

## 4. ทดสอบ
```bash
cd app
pip install -r requirements-dev.txt
python -m pytest -v tests            # 45 tests (ต้องมี company_data — ถ้าไม่มีจะข้าม 31 ข้อ)
python -m tools.compare_export data/exports/<ไฟล์>.xlsx    # เทียบโครงสร้างกับ Template
python -m tools.load_template_plan 10 2026                  # (ไม่บังคับ) โหลดเครื่องหมายแผนจาก Template sheet 10 เป็นงานแผน
```
